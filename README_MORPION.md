Un jeu de morpion interactif avec une interface graphique moderne et élégante.

An interactive tic-tac-toe game with a modern and elegant graphical interface.

- 📊 **Système de score persistant** / Persistent scoring system

- 🎯 **Mise en évidence des combinaisons gagnantes** / Winning combination highlighting

## Comment jouer / How to Play 🕹️

### Méthode 1: Lancer avec Python (Recommandé)

Exécutez simplement le lanceur Python qui ouvrira automatiquement le jeu dans votre navigateur:

```bash
python3 launch_morpion.py
```

### Méthode 2: Ouvrir directement dans le navigateur

Ouvrez le fichier `morpion.html` directement dans votre navigateur web préféré (Chrome, Firefox, Safari, Edge, etc.).

### Méthode 3: Via Python (Interface Tkinter - nécessite tkinter)

Si vous avez tkinter installé, vous pouvez utiliser la version Python pure:

```bash
python3 morpion.py
```

**Note**: Cette méthode nécessite que tkinter soit installé sur votre système.

## Règles du jeu / Game Rules 📋

1. Le jeu se joue sur une grille de 3x3 cases
2. Le joueur X commence toujours en premier
3. Les joueurs alternent en plaçant leur symbole (X ou O) dans une case vide
4. Le premier joueur à aligner 3 de ses symboles (horizontalement, verticalement ou diagonalement) gagne la partie
5. Si toutes les cases sont remplies sans qu'aucun joueur n'ait aligné 3 symboles, c'est un match nul

---

1. The game is played on a 3x3 grid
2. Player X always starts first
3. Players alternate placing their symbol (X or O) in an empty cell
4. The first player to align 3 of their symbols (horizontally, vertically, or diagonally) wins the game
5. If all cells are filled without any player aligning 3 symbols, it's a draw
